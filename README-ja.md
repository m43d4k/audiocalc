# AudioCalc

[English](README.md)

音楽制作・ミックス・マスタリング向けのオーディオ計算ツール集。
ブラウザだけで動作する静的Webアプリ。ログイン不要、トラッキングなし。

---

## ツール一覧

| ツール | 概要 |
|--------|------|
| **ノート ↔ 周波数** | 音名・MIDIノート番号・Hzを一覧表示。基準周波数（A=432〜444Hz）の変更、ピッチクラスフィルター、±½オクターブ列の表示切替、各音のサイン波試聴に対応 |
| **トランスポーズ** | 2つの音を選ぶだけで半音数と音程名（上行・下行）を表示 |
| **フェーズ → ディレイ** | 位相差（度）を入力すると、対応するディレイ時間をミリ秒・サンプル数で変換。lag/lead表示 |
| **ディレイ & リバーブ** | BPMを入力すると、ホール・ルーム・タイトの各設定に対するプリディレイ・ディケイ・トータル時間を計算 |
| **音価 ↔ 時間** | BPMを入力すると全音符〜64分音符、付点・三連符を含む各音符の長さをミリ秒で一覧表示 |
| **ms ↔ サンプル数** | サンプル数とミリ秒の相互変換。サンプルレートは 44.1/ 48 / 88.2 / 96 / 192kHz に対応 |
| **コムフィルター** | ディレイ時間から同相・逆相のコムフィルターノッチ周波数を計算。対数スケールの周波数レスポンス表示付き |
| **倍音列** | 基音周波数から倍音列を計算。周波数・最近音・セント偏差を一覧表示。スペアナ風グラフ付き |
| **Q ↔ 帯域幅** | ベルEQのQ値に対する帯域の広がりをオクターブ幅・Hz幅で確認。基準dBレベル切替（−1〜−12 dB）に連動したベルカーブ表示付き |

## 開発

### 必要なランタイム

[mise](https://mise.jdx.dev/) で管理（`mise.toml` に定義）。

```
Node.js 22 / Python 3.12
```

```bash
mise install
```

### コマンド

```bash
npm run dev        # Vite 開発サーバー起動（HMR）
npm run build      # TypeScript コンパイル + Vite ビルド → docs/
npm run preview    # docs/ のビルド結果をプレビュー
npm run typecheck  # 型チェックのみ（tsc --noEmit）
npm test           # Vitest（ウォッチモード）
npm run test:ui    # Vitest UI
```

### ビルド出力

`docs/` ディレクトリに出力されます（GitHub Pages 配信用）。

## 技術スタック

- **Vite 6** + **React 19** + **TypeScript 5**（strict モード）
- **plain CSS** + CSS カスタムプロパティ（デザイントークン）— CSS Modules / CSS-in-JS は使用しない
- **Vitest** + **@testing-library/react**
- **React Router v7**

### ソース構成

```
src/
  styles/
    tokens.css       # CSS カスタムプロパティ（デザイントークン）
    global.css       # リセット + ベーススタイル
  components/        # 共有 UI コンポーネント
  pages/             # 各ツールのページコンポーネント
  lib/               # 計算ロジック（純粋関数）
  data/
    tools.ts         # ツールメタデータ（ID・パス・アクセントカラー）
  i18n/
    index.tsx        # EN / JA 翻訳定義
  App.tsx
  main.tsx
```

計算ロジックは `src/lib/` に純粋関数として実装されており、React コンポーネントは表示のみを担当します。

### 規約

- **MIDI 規約**: C3 = MIDI 60（Yamaha / DAW 標準）、MIDI 69 = A3 = 440 Hz
- インデント: HTML / JS / TS は 2 スペース、CSS は 4 スペース
- 行末: LF、エンコーディング: UTF-8
